# BorrowBox

BorrowBox is a campus resource-sharing platform that allows students to lend and borrow items such as books, calculators, electronics, lab equipment, and academic resources.

## Features
- Student Profile Management
- Browse Available Items
- Add New Listings
- Borrow Requests
- Accept/Reject Requests
- Return Tracking
- Dashboard Analytics

## Tech Stack
Frontend:
- React
- Vite
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

Deployment:
- Vercel (Frontend)
- Render (Backend)

## Architecture

React Frontend
↓
Express REST API
↓
MongoDB Atlas
